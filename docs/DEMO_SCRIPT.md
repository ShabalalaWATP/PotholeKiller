## Failure recovery

- **API failure:** show the retry message, select **Use a sample instead** and explicitly disclose the predefined output. Never relabel it as live.
- **Map tiles unavailable:** keep the original hunt map; confirm only the fictional demo pin or use known coordinates. No real defect location has been verified by the schematic.
- **Application or venue connection failure:** play the existing local WebM and state that it is a recording of the earlier 60 XP version, without the new power controls. It has no audio narration.
- **Clipboard blocked:** open **Read the complete report** and show/select its text.
- **Repeat capture earns 0 XP:** explain the once-only rule. Do not claim another reward was earned.
