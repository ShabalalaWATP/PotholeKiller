# UK location and reporting lookup

`POST /api/location` accepts an explicit `{query}` search or `{lat,lng}` pin. All results use `LocationLookupResultSchema`; errors use `{error,code}`. Search suggestions always require the user to check and confirm the exact defect pin.

- Photon provides approximate UK address suggestions. The public server permits reasonable project usage, offers no availability guarantee and may throttle heavy traffic. Searches are user-triggered, with no autocomplete. The server identifies this app, spaces uncached Photon requests by one second per process and caches results briefly. See the [official Photon project and usage terms](https://github.com/komoot/photon#demo-server) and [API documentation](https://github.com/komoot/photon/blob/master/docs/api-v1.md). A high-traffic deployment needs a suitable dedicated provider and shared request protection.
- [Postcodes.io](https://postcodes.io/docs/postcode/lookup/) returns UK postcode centres and administrative codes. A [reverse lookup](https://postcodes.io/docs/postcode/reverse-geocode/) identifies a nearest postcode, not the precise administrative boundary. Full addresses containing a postcode can fall back to a clearly labelled postcode centre when address search fails. Existing map pins are never replaced with those centres.
- The checked-in directory comes from [GOV.UK Local Links Manager](https://github.com/alphagov/local-links-manager/blob/main/data/local-authorities.csv). Its generated metadata records the original Git blob SHA, retrieval date and licence. The snapshot contained 382 authorities when first downloaded. Retain `DIRECTORY_LICENCE.txt` when distributing it. Run `node lib/location/update-directory.mjs` to deliberately refresh the snapshot and review its diff.
- England's two-tier areas use the county highway authority. Other GB areas use the corresponding unitary authority. Northern Ireland public-road defects use [DfI's official nidirect route](https://www.nidirect.gov.uk/services/report-pothole-or-other-surface-defect), rather than the district council. Trunk, TfL and private roads can have different owners.
- Direct pothole-service links come from the [official local-transaction API](https://github.com/alphagov/local-links-manager/blob/main/docs/example-api-output.md), using service 557 and interaction 17. Those codes and county/unitary responsibility are published in [GOV.UK's pothole content API](https://www.gov.uk/api/content/report-pothole). Broken, insecure, mismatched or unrecognised-host results fall back to official national instructions and the known council website. Scotland uses [mygov.scot](https://www.mygov.scot/report-pothole).
- Only Hackney's independently verified published reporting email is currently enabled. Other authorities use their official form or website. Contact schemas bind saved authority identities and websites to the checked-in directory, constrain reporting/source hosts, and reject arbitrary inboxes. No email is guessed and no report is sent by this endpoint.

Request bodies, response sizes, external hosts, timeouts, concurrency, request rates and cache size are bounded. Location responses are not logged or persisted on disk. A ten-minute memory cache deletes response values proactively on expiry, including during idle periods. Per-process protections do not coordinate across serverless instances.

Live provider checks during implementation returned UK postcode results for London, Edinburgh, Cardiff and Belfast, a house-level Mare Street address match, a current Kent reporting form, and a broken Edinburgh service link that the app correctly treats as a fallback case. These observations are not a guarantee of future provider availability or address coverage.
