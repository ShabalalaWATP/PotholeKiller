# PotholeKiller

Next.js App Router, React, TypeScript and Tailwind. Keep the core application local-first and the OpenAI key server-side. Netlify Identity and Database support optional shared collector profiles.

- Use UK English and small focused modules, normally below 350 lines.
- `npm run dev` starts development. `npm run check` runs lint, types and unit coverage. `npm run build` creates the production application.
- Test classification gates, confirmed report locations, draft status, upload protection and once-only XP. Game bonuses use user-reported age and extent, never engineering danger. Sample outputs must always be labelled and must never be sent to a council.
- Avoid storing images or personal data in localStorage. Never claim submission or repair automatically.
- Use original creature art. Keep map attribution visible. Provide a local illustrated map when remote tiles are unavailable.
- Respect file ownership when using focused workers. The main agent owns final integration and verification.
- Use the official Identity SDK for authentication. Resolve community ownership on the server. Shared captures require an eligible live-scan receipt and database uniqueness constraints.
- Guest profile storage contains only a chosen public nickname and avatar. The Identity SDK manages its own session storage; do not duplicate email addresses or tokens in game data.
- UK address suggestions are approximate. Use verified authority routes, preserve source links, and confirm the exact road pin. Never infer council email addresses.
